# Support

Maru is a personal, in-development project. Support is best-effort.

## Where to ask

- Use GitHub Issues for reproducible bugs, regressions, feature requests, and
  documentation gaps.
- Use a security report instead of a public issue for vulnerabilities or anything
  involving credentials, tokens, private workspace data, or account access.

## Good support requests include

- The package or surface involved: desktop app, relay, provider, DevTools,
  browser, plugins, MCP, or remote pairing. (The mobile client is archived on
  the `archive/mobile` branch and is no longer actively supported.)
- Operating system and Maru version or commit.
- Clear reproduction steps.
- Expected behavior and actual behavior.
- Relevant logs or screenshots with secrets removed.

There is no guaranteed response time, but precise reports are much easier to
triage.

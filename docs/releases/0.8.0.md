# marudesk 0.8.0

Google 로그인, 멀티 프로바이더 관리, 사용량 대시보드, 그리고 에이전트가
스스로 컨텍스트를 관리하는 릴리즈. 원격 페어링은 cloudflared 자동 터널로
네트워크 설정 없이 가능해졌고, 수동 업데이트 확인도 시작 시 자동 체크와
동일한 인앱 경로로 통합되었습니다.

## Highlights

### Google 로그인 & 프로필 격리

릴레이 OAuth 핸드오프를 통한 Google 로그인이 추가되었습니다. 각 프로필은
독립된 웹 파티션(쿠키, 스토리지, 캐시)을 가지며, 프로필 전환기에서 바로
Google 계정을 연결/해제할 수 있습니다.

### 멀티 프로바이더 & 사용량 대시보드

여러 AI 프로바이더의 OAuth 인증을 한 곳에서 관리합니다. Device-code 흐름
UI, 자격 증명 교체, 멀티 크레덴셜 슬롯을 지원하며, 프로바이더별 비용
내역과 세션 히스토리를 보여주는 사용량 대시보드가 추가되었습니다. 셀프
호스팅 환경에서는 클라우드 릴레이 없이 직접 연결도 가능합니다.

### 자동 터널 (cloudflared)

원격 페어링 시 cloudflared를 자동으로 띄워 퍼블릭 터널 URL을 QR에
포함합니다. 포트 포워딩이나 네트워크 설정 없이 어디서든 폰으로 연결할 수
있습니다.

### 에이전트 개선

턴당 도구 호출 횟수를 제한하는 스텝 버짓, `/compact` 요약에 구조적
디테일을 더 보존하는 컴팩션 트레이스, 그리고 작업에 맞는 빌트인 스킬을
제안하는 스킬 서제스천이 추가되었습니다.

### 컨텍스트 윈도우 관리

StatusBar에 컨텍스트 사용량 링이 표시되며, 클릭하면 채팅으로 이동합니다.
컨텍스트가 거의 찼을 때 컴팩트를 권유하는 넛지가 매뉴얼 모드에서
나타납니다.

### Lanes 보드 — GitHub PR/CI 상태

각 워크트리 레인에 GitHub PR 번호(open/draft/merged/closed)와 헤드
커밋의 CI 결과가 표시되며, 클릭하면 인앱 브라우저에서 열립니다. 레인의
"dev URL 열기"는 기존 탭을 재사용합니다.

### 수동 업데이트 통합

"업데이트 확인" 버튼이 이제 시작 시 자동 체크와 동일한 electron-updater
경로를 사용합니다(Windows). 다운로드 진행률이 표시되고, 완료 후 "재시작하여
설치" 버튼으로 인앱 업데이트가 가능합니다.

## Install

- **Windows** — download **marudesk Setup 0.8.0.exe** and run it. Updates
  apply in place on the next launch/restart.
- **macOS** — download the `.dmg` for your chip (**arm64** for Apple
  Silicon, **x64** for Intel), open it, and drag marudesk to Applications.
  The build is unsigned, so on first launch right-click the app → **Open**
  to bypass Gatekeeper.
- **Linux** — download the **AppImage** (`chmod +x` then run) or the
  **.deb** (`sudo dpkg -i marudesk_0.8.0_amd64.deb`).
- **Android** — download **marudesk-0.8.0.apk** and sideload it. You may
  need to enable "Install from unknown sources" in your device settings.
  This is a debug-signed build; the phone is the thin client for the PC
  agent — see the mobile README for pairing instructions.

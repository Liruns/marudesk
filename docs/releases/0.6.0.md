# marudesk 0.6.0

Workspace splitting gets a real workflow. This release adds a **split picker**
(choose which workspace and direction), **drag-to-split** from the rail, and
a **quick zoom control** in the status bar — plus bug fixes for pane ID
collisions and close-pane focus.

## Highlights

### Workspace split picker

The split button now opens a picker popover listing every workspace with
**right** and **down** direction buttons. No more splitting-and-then-switching:
pick the target workspace and orientation in one click.

### Drag-to-split

Workspace rail buttons are now draggable. Drag a workspace onto any pane edge
(left, right, top, bottom) and a semi-transparent accent overlay previews the
split. Drop to create the split with that workspace in the matching direction.

### Quick zoom in the status bar

The existing Interface Zoom setting (50–200%) is now surfaced as **−/100%/+**
controls in the status bar. One click to zoom in or out by 10%; click the
percentage to reset to 100%. Accent-colored when zoomed so you always know
the current scale — handy on small monitors where split panes feel cramped.

### Bug fixes

- **Pane ID collision** — newly created pane IDs used a sequential counter that
  started at 0 on every launch, colliding with persisted layout IDs after
  restart. IDs now include a random suffix.
- **Close-pane focus** — closing a split pane used to jump focus to the first
  leaf in the tree. It now focuses the sibling pane (the one that expands to
  fill the closed pane's space).

## Install

- **Windows** — download **marudesk Setup 0.6.0.exe** and run it. Updates apply
  in place on the next launch/restart.
- **macOS** — download the `.dmg` for your chip (**arm64** for Apple Silicon,
  **x64** for Intel), open it, and drag marudesk to Applications. The build is
  unsigned, so on first launch right-click the app → **Open** to bypass
  Gatekeeper.
- **Linux** — download the **AppImage** (`chmod +x` then run) or the **.deb**
  (`sudo dpkg -i marudesk_0.6.0_amd64.deb`).
- **Android** — download **marudesk-mobile-0.6.0-debug.apk** and sideload it
  (unsigned debug build).

# MaruDesk 0.1.0

_Released 2026-06-07_

The first feature release of MaruDesk. This cuts a single `0.1.0` repository
version across all three packages — the desktop app (`marudesk`), the mobile
thin client (`mobile`), and the relay/auth service (`relay`) — and bundles the
diagnostics, language-server, agent-tooling, and profiles work that landed
since `0.0.4`.

MaruDesk is an agentic desktop workspace that fuses a real Chromium browser,
a Monaco editor and terminal, and a multi-provider AI agent — so the agent can
read and act on your **running** app, not just its source.

> Status: in active development, built as a daily driver and portfolio
> project. Expect rough edges.

## Highlights

### 🔎 Language intelligence & diagnostics

MaruDesk now understands the health of your code as you work, and lets the
agent act on it.

- **Checker-driven diagnostics backend.** A pluggable backend runs project
  checkers and exposes results through a `read_diagnostics` context source and
  a gated `run_diagnostics` agent tool.
- **Tier 2 Language Server engine.** Real LSP integration with live
  diagnostics, truncation-safe document synchronization, server
  initialization options, and a status surface that shows what's running.
- **Problems surfaced everywhere.** A Problems indicator, Monaco editor
  squiggles, and a Problems list popover with jump-to-line.
- **Externalized recipes.** Checker recipes live in `languages.json` (ships
  with an ESLint recipe), with more robust command resolution so checkers find
  the right binary.

### 🤖 Agent capabilities

- **`run_command`** — a gated tool that runs workspace commands on the agent's
  behalf.
- **Tab-control MCP tools** — open, activate, navigate, and close browser tabs
  programmatically.
- **Detached background agents** — spawn, collect, and cancel long-running
  agents that work while you keep moving.
- **Embedded Chromium via `chrome-devtools` preset** — drive the in-app
  browser through the standard chrome-devtools MCP preset.
- **Better autonomous research** — `spawn_subagent` is now usable for
  autonomous research, and turn-completion receipts are correctly scoped to
  the last turn.

### 👤 Profiles & workspaces

- **App profiles.** Full application profiles with fully isolated data sets,
  switchable from a title-bar profile switcher.
- **Richer pane header.** An identity avatar plus folder / SSH badges so it's
  clear what each pane is pointed at.
- **Smoother workspace setup.** "Add SSH folder" is folded into the New
  Workspace flow.
- **Layout that persists.** The deck split layout is saved and restored, and
  the workspace registry survives restarts.

### 🪟 App & UX

- **Splash window** while the app loads.
- **Interactive product tour** — a step-through introduction to the surfaces.
- **Empty-stage screen** for panes that have no tabs yet.
- **First-run guidance** for new installs and the no-workspace state.
- **Window state persistence** — size, position, and maximized state are
  restored on relaunch.
- **Polish & fixes** — UX refinements from a screenshot review, a larger
  app-icon mark, and fixes for workspace switching, editor focus, `Ctrl+W`,
  last-tab close, and IPC return-literal hardening.

## Install & run

There is no root package; install per package (Node.js 20+).

```bash
cd marudesk
npm install
npm run dev          # Vite renderer + Electron shell
```

Build a desktop package:

```bash
cd marudesk
npm run build        # type-check + bundle
npm run package:win  # or: npm run package:mac
```

See the root [`README.md`](../../README.md) for the full setup, provider
configuration, and verification flows.

# marudesk 0.0.3

Second feature release for the MaruDesk desktop app (`marudesk` 0.0.2 → 0.0.3).
Covers pull requests [#18][#18]–[#39][#39] merged after the 0.0.2 baseline.

**Full changelog:** https://github.com/Liruns/marudesk/compare/v0.0.2...v0.0.3

## Highlights

- **User plugin runtime** — isolated `utilityProcess` JS plugins that contribute
  agent tools and slash commands, with host-mediated fs/net access and sandboxed
  `plugin://` iframe UI panels. ([#34][#34])
- **SSH remote workspace roots** — mount remote hosts as first-class workspace
  roots and read/edit their files. ([#35][#35])
- **Workspace deck lifecycle** — add, rename, reorder, and remove workspaces
  straight from the deck rail. ([#18][#18])
- **Advanced agent prompting** — trust-boundary prompt-injection hardening,
  sticky keyword modes, `AGENTS.override.md`, `@`-import expansion, runtime
  context, approval-mode + global instructions, and a per-turn context hook.
  ([#39][#39])

## Added

- Plugin runtime: P1 isolated runtime + sandbox + harness, P2 settings panel +
  slash-command contributions, P3 diff-visible `fs:write` + host-mediated net,
  and v2 sandboxed `plugin://` iframe UI panels. ([#34][#34])
- SSH remote workspace roots (read + edit). ([#35][#35])
- Manage the workspace lifecycle from the deck rail. ([#18][#18])
- Absorb 5 additional OpenAI-compatible API-key providers (+ expansion plan).
  ([#29][#29])
- Render agent-generated images and videos inline in AI Chat. ([#21][#21])
- Line-addressable (paged) agent file-read tools, replacing the fixed 16 KB
  byte window. ([#22][#22])
- Search: glob filters, highlighted previews, and jump-to-line. ([#27][#27])
- `/compact`: non-destructive history, auto-compaction, and tail preservation.
  ([#28][#28])
- Settings: cross-category search, gear-menu launcher, Appearance gaps, and a
  Ctrl/Cmd+, shortcut. ([#24][#24], [#26][#26])
- AI chat composer redesign, drawer/chrome polish, and AgentChat
  modularization. ([#37][#37])
- Advanced agent prompting + per-turn context hook. ([#39][#39])
- Enrich external MCP tool-result content mapping. ([#31][#31])

## Fixed

- Stop duplicating workspaces on legacy re-list. ([#20][#20])
- Fix context-panel sizing, model-picker visibility, and the split tab-close
  crash. ([#23][#23])
- Media-generation fallback, session read-tracker reset, and patch symlink
  guard. ([#25][#25])
- Fix a category-aware Settings search regression and dedup the accent picker.
  ([#26][#26])
- Keep split-deck panes full height so selected tabs render. ([#32][#32])
- Preserve sibling workspace browser panes / fix pane repaint. ([#38][#38])
- Guard marudesk dev-reload IPC `EPIPE` errors. ([#36][#36])
- Accept `pending` in the xAI video status enum. ([#19][#19])

## Docs

- Plugin runtime design (utilityProcess-isolated JS plugins). ([#33][#33])
- Multi-provider subagent (parallel agents) design. ([#30][#30])

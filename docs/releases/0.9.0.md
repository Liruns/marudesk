# Maru 0.9.0

MaruDesk가 **Maru**로 새 이름을 달고, **인피니트 캔버스**가 앱의 기본
서피스가 되는 릴리즈. 브라우저·에디터·터미널·AI 에이전트가 탭 스트립과
분할 그리드 대신 자유롭게 배치·확대/축소되는 카드가 됩니다. 여기에 캔버스
위에서 작업을 분해·실행하는 **AI Work OS(Task 노드)**, 새로운 빌트인
프로바이더, 그리고 폰 원격/릴레이 스택 제거가 더해졌습니다.

## Highlights

### Maru 리브랜딩

제품 표시 이름이 **MaruDesk → Maru**로 바뀌었습니다(홈 히어로, 창/스플래시
타이틀, 패키징 메타데이터, 문서). 코드네임 `marudesk`, 앱 ID
(`com.marudesk.app`), 레포, `marudesk` PATH 명령은 그대로라 Windows 인앱
자동 업데이트가 기존 설치를 그대로 인플레이스로 갱신합니다.

### 인피니트 캔버스 — 새로운 기본 서피스

브라우저, 에디터, 터미널, AI 에이전트가 패닝·줌 가능한 캔버스 위의 자유
카드가 됩니다. 패닝·드래그·리사이즈는 DOM에 직접 반영되어 어떤 줌 레벨에서도
부드럽게 동작합니다.

- **여러 개의 이름 있는 캔버스** — 워크스페이스별로 캔버스를 만들고, 전환·
  이름 변경·삭제·**복제**할 수 있으며, 배치는 패널 콘텐츠 기준으로 저장되어
  전체 재시작 후에도 유지됩니다.
- **Figma 스타일 편집** — 다중 선택, 마퀴, 함께 이동, 명시적 팬 모드, 키보드
  내비게이션과 넛지, 줌 인식 정렬 스냅, 캔버스 안 워크스페이스 전환기.
- **섹션 & 엣지** — 카드를 라벨이 붙은 중첩 가능한 섹션으로 묶고, 히트 테스트된
  연결점으로 방향성 있는 엣지를 그어 카드끼리 연결합니다.
- **카드 어포던스** — 잠금/최대화, 탐색기에서 파일을 드래그해 패널로 열기,
  각자 독립된 대화를 가진 동시 AI Chat 카드, 실제 브라우저처럼 동작하고 콘텐츠
  줌 스케일링이 되는 웹 카드, 별도 창이 아니라 캔버스 카드/탭으로 열리는
  DevTools, 미니맵, 작은 카드에 맞춰 reflow되는 반응형 레이아웃.

### AI Work OS — 캔버스 위의 Task 노드

캔버스 위에 작업을 노드로 올립니다. 순수 의존성 스케줄러(shared)를 가진
task-graph 스키마, 목표를 task 그래프로 분해하는 AI 디컴포저, 그리고 생성·
편집·실행할 수 있는 Task 노드가 추가되었습니다. 에이전트는 MCP를 통해 직접
캔버스 Task 노드를 만들 수 있습니다.

### 새 프로바이더 & 프로바이더 UX

빌트인 프로바이더로 **Moonshot, NVIDIA, Venice, Hugging Face**가 추가됐습니다.
프로바이더 설정 UX도 다듬어졌습니다 — API 키 딥링크, 커스텀 엔드포인트 프리셋,
프로바이더별 배지와 모델 수, 인라인 키 에디터, 그리고 실제 결과를 정직하게
보여주는 **Test connection**. 구독/OAuth 프로바이더는 에디터 user-agent를
강제하고 Copilot 다이얼렉트 라우팅을 올바르게 처리하며, GitLab Duo 트랜스포트가
실제 동작에 맞게 정리됐습니다.

### 수정 & 다듬기

- 임베디드 웹 탭이 Google Chrome UA-CH 브랜드를 제시해 Chrome을 게이트하는
  사이트가 정상 동작합니다.
- Ctrl+휠 줌이 부드럽게 이징되고 멈췄을 때 텍스트가 또렷합니다.
- 설정 패널이 좌우 분할 레이아웃을 사용합니다.
- 턴이 끝난 뒤에도 AI Chat 컴포저가 IME 안전 상태를 유지합니다(한글/CJK 조합이
  끊기지 않음).

### 제거 / 아카이브

- **폰 원격 / 릴레이 스택이 제거**되었습니다(로컬 CLI 브리지는 유지). 폰
  페어링, 클라우드 릴레이, cloudflared 자동 터널은 더 이상 앱에 포함되지
  않습니다.
- Capacitor 모바일 thin client는 `archive/mobile` 브랜치(태그
  `archive/mobile-v0.8.0`)에 아카이브된 상태이며, 활성 워크스페이스에는
  포함되지 않습니다.

## Install

- **Windows** — download **Maru Setup 0.9.0.exe** and run it. Updates apply
  in place on the next launch/restart (existing MaruDesk installs upgrade in
  place — the app id is unchanged).
- **macOS** — download the `.dmg` for your chip (**arm64** for Apple
  Silicon, **x64** for Intel), open it, and drag Maru to Applications.
  The build is unsigned, so on first launch right-click the app → **Open**
  to bypass Gatekeeper.
- **Linux** — download the **AppImage** (`chmod +x` then run) or the
  **.deb** (`sudo dpkg -i maru_0.9.0_amd64.deb`).

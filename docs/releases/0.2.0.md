# marudesk 0.2.0

The release that takes marudesk cross-platform. The desktop app now ships for
**macOS and Linux** alongside Windows, all built and published by a new CI
pipeline — and under the hood it grows from a code-aware chat surface into a
**runtime-aware agent control room**: concurrent agents on isolated worktrees,
a lanes board to drive them, turn-level rollback that restores the running page,
and a live evidence timeline you can act on.

## Highlights

### Cross-platform desktop builds
- **macOS support** — `dmg` builds for both Apple Silicon (arm64) and Intel
  (x64). The app draws its own chrome flush to the top edge with the native
  traffic-light buttons in place.
- **Linux support** — `AppImage` (portable, run-anywhere) and `deb` packages
  (x64).
- **CI release pipeline** — a GitHub Actions workflow builds marudesk on native
  runners per platform/arch (macOS arm64, macOS x64, Windows x64, Linux x64) and
  publishes every installer to the matching GitHub release on each `v*` tag.
- Windows keeps its in-app auto-update via `electron-updater`. macOS and Linux
  are download-and-run for now (the Mac build is unsigned; auto-update there
  needs Apple code signing + notarization).

### Mission Control — runtime-aware agents
- **Worktree lanes board** in Source Control: each agent runs on its own
  isolated git worktree. Spin up a **per-lane dev server** and open it in the
  browser, **open a PR per lane** (push + GitHub compare), **merge a lane**, and
  **discard stale agent worktrees** — all from the board.
- **Turn checkpoints** — roll the whole working tree back to any prior turn, and
  on a runtime-aware revert, restore the live page along with the files.
- **Supervisor rail + Specs panel** — a spec lifecycle (draft → active → review
  → done) with storage and IPC, surfaced in the context rail.
- **Actionable evidence timeline** — a runtime evidence panel that streams agent
  page-actions and edit provenance, with inline Fix / Triage actions.
- **Element fix-loop** — pick an element on the live page, jump to its
  ranked source file, and let the agent close the loop; picked elements are
  highlighted and revealed so they can't hide behind a closed drawer.
- **Cached browser workflows** — save a sequence of page actions and replay it
  model-free.
- **Floating in-page stage toolbar** for driving the browser stage.
- **Steering files** — `.marudesk/steering/*.md` load as standing project
  guidance for the agent.
- **Toggleable runtime tool groups** — see and switch the agent's tool surface
  from settings.
- **Preview gated browser actions** on the page before you approve them.

### Concurrent agents (Stage 12)
- **Worktree isolation engine** with per-thread isolation, so concurrent
  conversations don't step on each other's files.
- **Thread registry** — switch between concurrent conversations.
- **True concurrent foreground execution** — run agents at the same time.
- **Scheduled automations** — saved-prompt agents that run on a schedule.

### Agentic Chat v5 / v6
- Two rounds of weak-feature hardening plus a 2nd-generation reference UI/UX
  pass across the chat surface.
- **Live-streamed foreground subagent output** rendered onto its card.
- **Read-view hash anchors** for token-cheap edits.

### Mobile & MCP
- **Mobile** — steerable plan and approval-mode parity with the desktop host.
- **MCP** — per-tool confirm gating for trusted servers.

### Polish & fixes
- Global 1.5px Lucide icon stroke for a consistent icon weight.
- Dependency hygiene, shared-helper extraction, and harness/e2e repairs from
  code review.

## Install

- **Windows** — download **marudesk Setup 0.2.0.exe** and run it. Updates apply
  in place on the next launch/restart.
- **macOS** — download the `.dmg` for your chip (**arm64** for Apple Silicon,
  **x64** for Intel), open it, and drag marudesk to Applications. The build is
  unsigned, so on first launch right-click the app → **Open** to bypass
  Gatekeeper.
- **Linux** — download the **AppImage** (`chmod +x` then run) or the **.deb**
  (`sudo dpkg -i marudesk_0.2.0_amd64.deb`).

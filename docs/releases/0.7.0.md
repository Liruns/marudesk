# marudesk 0.7.0

The agent now **verifies what it changed** — with its own eyes. This release
adds a screenshot tool that puts the live page in front of vision models, an
exception trap that captures local variables at the moment of a crash, a
full-stack network triage tool, and one-click **Fix this** for terminal
errors. Around the agent, the editor grows IntelliSense and git
gutter/blame, Source Control gains stashes and merge-conflict resolution,
the browser gets bookmarks, address-bar suggestions, and tab groups, the
custom DevTools take a major parity leap, and the phone can now review and
revert the agent's edits.

## Highlights

### The agent sees the page (`screenshot`)

After an edit-and-reload, the agent can capture the live tab and — on
vision-capable models — actually look at it. The closed loop becomes
`edit → reload_and_verify → screenshot → "does it look right"`. Models whose
providers can't carry images get an honest text fallback.

### Crash-time evidence (`arm_exception_capture`)

Arm the trap, reproduce the error, read the snapshot: exception description,
top call frames, and **the local variables of the failing frames**, captured
at pause time and auto-resumed. No DevTools pausing, no manual stepping.

### Full-stack triage (`triage_network_failure`)

A failed request is often a backend problem. Given a requestId, the agent
correlates the request with recent scrollback across every open terminal —
multi-root workspaces (FE + BE) mean the same agent can read the 500's stack
trace from the backend dev server and fix the backend source.

### Fix this, now for terminals

Build failures, test failures, and runtime stack traces are detected in
terminal scrollback (secret-scrubbed, deduped), badge the terminal pane, and
carry the same one-click **Fix this** handoff as console errors.

### An editor that pulls its weight

TypeScript/JavaScript IntelliSense (completions, hover, go-to-definition
across open files), format on save, a git diff gutter, and inline
current-line blame. Source Control adds **stashes** and **merge-conflict
resolution** — accept ours/theirs per file, Continue/Abort the operation,
and accept current/incoming/both codelenses right on the conflict markers.

### A browser you can live in

Bookmarks with a history library, address-bar suggestions (bookmarks +
frecency-ranked history with token highlighting), and **tab groups** —
named, colored, collapsible chips that survive a restart.

### DevTools parity leap

Sources/debugger panel (source maps, DOM breakpoints, watch expressions),
performance profiler and security panels, HAR export, coverage, WebSocket/
SSE frame inspection, IndexedDB/cache-storage views, storage editing, an
Elements Computed pane with the box-model diagram, and tabbed network
details (Headers / Payload / Response / Timing / Initiator).

### The phone reviews the diff

Mobile shows per-edit unified diff cards (+N/−M, expandable, revert applied
edits) and proposed diffs above Approve/Deny — plus local notifications when
a background agent finishes or an approval arrives while the app is
backgrounded.

### Built-in skills, costs, and safety

- `save-regression-test` turns a verified runtime fix into a Playwright
  regression test; `write-plugin` authors a workspace plugin through the
  capability-gated runtime.
- Estimated conversation cost (USD) next to the context gauge and in
  `/context`.
- SSH host keys are pinned on first sight and verified on every connect —
  a mismatch refuses the connection with an actionable error. Manage pinned
  keys in Settings → Remote.

## Install

- **Windows** — download **marudesk Setup 0.7.0.exe** and run it. Updates
  apply in place on the next launch/restart.
- **macOS** — download the `.dmg` for your chip (**arm64** for Apple
  Silicon, **x64** for Intel), open it, and drag marudesk to Applications.
  The build is unsigned, so on first launch right-click the app → **Open**
  to bypass Gatekeeper.
- **Linux** — download the **AppImage** (`chmod +x` then run) or the
  **.deb** (`sudo dpkg -i marudesk_0.7.0_amd64.deb`).
